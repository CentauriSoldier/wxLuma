# Future additions

Ideas for future development. These are proposals, not implementation commitments.
All additions should follow the existing code and naming conventions, support
skinning and appropriate image assets, and include events, audio hooks, state
support where applicable, documentation, and demo examples.

## First priority: drag-and-drop support

Reorder list entries, move tree nodes, and accept files. Provide drag previews,
drop target feedback, validation, cancellation, and events. This would improve
several existing controls.

## Other candidates

- **Rich text / markup label:** Mixed colors and fonts, clickable links, and
  inline icons. Useful for game logs and tooltips.
- **Command palette:** Searchable actions with keyboard navigation, icons, and
  shortcuts.
- **Timeline:** Events, selectable ranges, zoom, and draggable markers.
- **Virtual joystick / XY pad:** Two-axis input with configurable bounds, a dead
  zone, and optional spring return.
- **Canvas / viewport:** Pan, zoom, layers, image overlays, and hit testing.
